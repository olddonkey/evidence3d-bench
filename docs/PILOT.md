# Astra 的首轮生成试验

这是开发试跑：固定 GPT-6-Astra 与 Codex CLI，先检查完整交付链路，再讨论多次运行和正式比较。结果同时依赖模型、提示、工具和预算，不能直接解释成模型本身的能力排名。

## 固定条件

- 精确模型名 `gpt-6-astra`，推理等级 `high`，不自动替换模型。
- 每题新建一次 `codex exec`，不继承本对话、记忆、全局技能或旧工程。任务顺序写入 manifest。
- 本地 Node、Three.js 0.180.0、Blender 5.2.1 LTS；实际可执行路径和 CLI 版本入档。
- 每题一次，最多使用任务原定的 1800 秒。允许在这次作答中自查和修改，不向模型反馈评分，不代替它修复输出，不挑选多次作答中的最佳结果。
- 计时从 CLI 启动到进程退出，含推理、工具执行和等待；超时终止整个进程组。原始 JSONL、错误、失败和缺失产物均保留。
- 使用现有 Codex ChatGPT 登录。没有 API key 创建、凭据转存或 Git 上传；模型推理会通过该登录连接 OpenAI，不能称为离线推理。费用未知保持 null，记录 CLI 返回的 token 用量。

## 输入隔离

每个工作目录只有标准输入包、通用 Three.js 依赖、空输出目录和工作临时目录。Seatbelt 文件策略让输入只读，允许写本题工作目录；仅开放系统／开发运行库和 Blender 的读取。生成命令不能读取旧工程、评分代码、私有真值、全局记忆和认证文件，也不能通过本地服务或互联网取得额外资料。

启动前运行真实的允许／拒绝检查：输入可读、输入不可写、输出可写、目录外 canary／符号链接／评分代码／记忆／认证文件不可读、Three 可读、本地网络被禁止。配置或提示、任务输入、参考和运行库改变后拒绝静默复用原实验。检查仅验证这里实际使用的命令边界，不等于经过第三方认证的防作弊环境。

Codex 的自带网页、插件、连接器、多 agent 和图像生成在此运行中关闭；本地图片检查和建模工具仍可用。权限策略只约束模型的本地命令，服务端模型连接由宿主负责。参见 [OpenAI 权限文档](https://learn.chatgpt.com/docs/permissions#scope-and-enforcement)。

## 运行

准备默认四个合成细节题，只冻结材料，不开始推理：

    node scripts/run-pilot.mjs --mode prepare --id astra-cal-20260911-01

运行隔离检查：

    node scripts/run-pilot.mjs --mode preflight --batch .local/pilots/astra-cal-20260911-01

开始串行作答并在每题结束后评测：

    node scripts/run-pilot.mjs --mode run --batch .local/pilots/astra-cal-20260911-01

选定其他任务时，在 prepare 添加 `--tasks in-n-out,fenchurch`；可通过 `--codex` 和 `--blender` 指定本机程序路径。新实验必须使用新 id。此入口没有自动重跑失败题或续跑开关。

每题必须实际交付 `output/model.glb`，同时保留可编辑构建源码与 `output/notes.md`。GLB 先验格式、三角面和预算，再按该题预先锁定的参考评测。完成且可评分的合成提交会进入现有「细节校准」和匿名逐项评分候选池。

`.local/pilots/<id>/` 保留 manifest、输入／运行库哈希、命令、提示、隔离检查和汇总。每题下有原始事件、输出、产物哈希和 report.json。该目录由 Git 忽略，材料与原始日志不公开。

## 如何读第一轮结果

| 结果 | 报告内容 | 不能推出 |
|---|---|---|
| 交付能力 | 成功、失败、超时、实际耗时、token、GLB 技术检查 | 格式有效不表示形状准确 |
| 合成几何 | 尺寸／位置误差、固定视角 IoU、通过的局部检查及每项误差 | 局部通过率不是人工视觉分或总体质量分 |
| 真实对象 | 模型、原始资料、建模假设、技术检查 | 真值仍待核验，不能填准确性总分 |
| 人工视觉／细节 | 沿用独立评审和 0–4 分锚点，未知项保留为空 | 不由生成模型给自己打分，也不伪造评审 |

四个合成题公开给出了完整参数，测试的是明确资料下的构建能力。真实开发对象在旧流程中已经使用过，也不能称为未见过的保留集。每题只有一次，无法估计成功率稳定性或置信区间。后续应锁定同一套框架，用至少三次独立运行比较模型，并加入按对象保留的新任务。
