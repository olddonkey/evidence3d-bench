# 从校准原型进入真实试验

v0.3 已完成全局和局部几何校准、四组细节示例、固定局部视角、逐项人工评分及按任务登记新提交。后续先完成以下工作，再发布真实对象成绩。

## 首批真实标注

本地 .local/annotations/ 已为 Westminster、Fenchurch、Kingsfold、In-N-Out、Gasholders、Stanford Dish 和 Green Library 创建标注工作表。

每题还附有十张带原始照片区域的细节草案，文件为 details-TASK.json。它们没有独立审批、世界相机或容差，不可直接作为评分真值。需在这些草案上完成确认、修正和遮挡处理。

每题至少两位独立评审者核验：

1. 目标对象、范围与时间状态。
2. 米制尺度、原点、方位和高度基准。
3. 可从输入独立确认的尺寸及来源位置，允许区间与误差容差。
4. 关键部件关系，以及确实未知的部分。
5. 用于照片对比的相机与遮挡标注。
6. 资料的公开分发许可。

首次可以只核验少量明确尺寸，采用 measurement_only，不需要先获得完整参考网格。任何没有证据的立面、内部或细节都保持未评分。

## 先校准人类与自动判断

使用匿名工作台和逐项评分页收集独立人工判断；已经看过缺陷答案的参与者使用练习模式。检查人际分歧、左右顺序敏感性，以及自动测量是否遗漏人认为重要的结构问题。视觉忠实度与审美偏好分开进行。

模型裁判今后只能在单独的影子实验中参与。先对未参与调参的人工样本验证其一致性、偏好和遗漏模式，再讨论是否替代部分人工工作。当前没有此类实验结果。

## 真正的生成实验

锁定任务版本后，增加一个隔离 runner：只挂载导出的输入包与空输出目录；固定工具版本；记录实际资源预算与全部失败；禁止读取旧答案。分别进行底层模型固定框架比较和完整系统比较。

每个真实对象进行重复运行。旧工程里已经反复建模的对象用于开发，不用于声称“未见过的真实对象能力”。正式测试还需要新的、按对象分组保留的数据。

## 当前明确不做的推断

- 22 项校准检查通过，不等于真实世界评分已可靠。
- 真实 GLB 能导入，不等于建筑几何准确。
- 人类更喜欢某个模型，不自动说明其尺寸更正确。
- 多个 AI 裁判意见一致，不等于没有共同偏差。
- 没有独立真值的指标不填零、不补权重、不参与伪精确综合排名。
