# v0.1 评分协议

协议标识：evidence3d-geometry-v0.1.0。该版本输出可复算的原始指标，不输出综合质量分或全系统排名。

## 评分与数据的信任边界

任务、输入文件、提交 GLB 和参考网格分别锁定 SHA-256。任务 revision 使用按键排序的 canonical JSON 哈希，避免 JSON 缩进影响身份。报告记录任务、提交、产物及真值的哈希，并记录评分源码与 schema 的联合指纹，以及 Node / Three.js 版本。

输入哈希不符时拒绝运行；参考数据或参考范围配置错误归为 evaluation_error，不归咎于提交者。节点名、材质名、extras、提交说明与代码文本都不用于计算几何分。

GLB 读取不执行提交者的生成代码，也不下载依赖。几何计算只读取实际场景中三角形引用的位置，应用节点世界变换；未引用的孤立顶点不能人为扩大 bbox。技术有效不等于语义正确或完整 glTF 规范认证。

本仓库中的 private 只是组织边界。HTTP 不提供私有标签文件，但具有本地文件权限的进程仍能读取它。正式测试必须另行实现文件系统隔离。

## 原始指标

### 世界坐标尺寸

对三角形中被引用、变换后的全部顶点计算 xyz 轴对齐包围盒。

每轴分别报告参考长度、实测长度、绝对误差、相对误差和中心偏差。

- 相对尺寸误差 = abs(实测长度 - 参考长度) / 参考长度。
- 中心偏差 = abs(实测 bbox 中心 - 参考 bbox 中心)。
- 维度和位置通过条件分别使用真值中预先冻结的米制容差。
- 不做刚体配准或尺度拟合，不把单位错误自动修复掉。

单个离群顶点和多余地面会影响 bbox，因此任务明确排除场景装饰；bbox 必须结合轮廓和后续语义检查解读。

### 固定方向投影

参考配置指定每个视角的正交基、原点、范围和分辨率。候选与参考共用该配置。

对三角形进行双面投影，按像素中心是否位于三角形内计算二值覆盖。退化投影不产生面积。当前合成校准使用 192 × 192，包含正面、侧面、俯视与两个斜视。

- IoU = 重合像素 / 并集像素。
- Precision = 重合像素 / 候选覆盖像素。
- Recall = 重合像素 / 参考覆盖像素。
- 空候选得零；空参考是评分配置错误。
- 超出评测范围的顶点单独记录，该视角不能通过，防止裁切掩盖多余几何。
- 各视角保留原始结果，同时提供 mean/min IoU 供诊断；不是模型综合质量分。

校准通过阈值为 IoU ≥ 0.985、尺寸误差 ≤ 0.01 m、中心偏差 ≤ 0.01 m。这些阈值只针对解析合成任务，不能直接用于真实建筑。

## 真值方式

### mesh_reference

用于已有可信完整几何参考的对象。参考 GLB、自洽的解析或独立标注 bbox、视角与容差必须一起锁定。参考 GLB 与所声明 bbox 不一致时，评分失败。

合成样例由明确列出的箱体、三角形屋顶及独立枚举的范围构成；已知正确产物只用于评分器校准，不是对真实建筑准确性的证据。

真实对象的配置要求 independent_review 来源、至少两个不同的 reviewer 标识及证据记录。这些是人工审核声明，不是自动签名认证系统。

### measurement_only

适用于只有部分可信尺寸、没有完整扫描的对象。每个测量项包含：

    {
      "id": "overall-height",
      "kind": "bbox_dimension",
      "axis": "y",
      "accepted_interval_m": [29.8, 30.2],
      "tolerance_m": 0.1,
      "source_ids": ["source-2"]
    }

以上数值是字段说明示例，不能直接用于任何真实题。

实测值落在 accepted_interval_m 内时，距区间误差为零；否则取到最近端点的距离。该距离不超过 tolerance_m 才通过。可信区间反映资料不确定性，额外容差是预先约定的允许建模误差。两个概念必须在独立标注时分别说明。

measurement_only 真值文件包含 schema_version、task_id、task_sha256、mode、provenance 和 measurements；不需要 reference GLB。每项必须引用实际输入 source id。

报告中只有已标注项可评分。没有完整轮廓真值时，轮廓指标为 null，不能改成零，也不能把缺项权重转移给容易测的项目。通过只代表所列尺寸通过，不代表整个对象正确。

## 不变性与缺陷检出

每个解析对象包括：

- 原样对照。
- 改材质、改命名／增加等价层级、转成等价非索引顶点。
- 宽度增加 5%、10%、20%。
- 缺少关键构件。
- 深度压缩为原来的 1.5%。
- 左右镜像。
- 整体上移 2 米。
- 外部 buffer 和空产物两个无效提交。

不变性要求几何指标一致；尺度扰动检查测得的误差与独立设定的比例一致且单调增加；其余指定缺陷要求被相应测量检出。软件测试另有完整正方形像素覆盖等独立解析断言。

这些测试不证明所有缺陷都会被发现。重复重叠表面、隐藏内部错误、法线或拓扑问题可能逃过当前指标。

## 人工偏好

每位评审者得到打乱顺序的十组配对，并额外看到一组左右互换的复测。候选位置根据随机 session id 分配；身份映射与原始标签不会随 ballot 发给浏览器。GLB 视图删除名字、extras、颜色与材质，客户端重算灰模法线，使用相同的框架与相机尺度。

五种判断分别保存：A、B、平局、两个都不好、资料不足。后台转成与左右呈现无关的 canonical 选择。

偏好汇总每人每组只取一票，顺序复测独立计算一致率。明确 A/B 选择的胜率附 Wilson 95% 区间；该区间不包括平局类，也不代表跨对象泛化置信区间。跨对象系统比较尚未实现，需要按真实对象聚类重采样，不能把同一对象的视角当成独立样本。

practice 永不计入 human 统计。自动化测试的数据位于临时目录；界面连通性测试明确保存为 practice。没有调用模型裁判或自动伪造人类偏好。

## 正式榜单仍需补齐

1. 真实任务的独立来源、年代、坐标、误差、遮挡与权利标注。
2. 能见到输入但无法读取私有真值的生成 runner。
3. 受信任的耗时／费用／重试记录与固定预算。
4. 人类和自动指标在未用于调参的样本上的一致性验证。
5. 按对象划分的开发／测试集与统计不确定性。

提交文件中的 resource_accounting 无法自证其可信性。v0 不因为写入 runner_measured 就允许进入正式排名。
